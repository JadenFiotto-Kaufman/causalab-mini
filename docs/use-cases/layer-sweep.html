Use case · worked example

Layer sweep: where is "today" held?

One document, 32 experiments. Interchange the residual stream between two prompts at every layer, at two positions, and watch the answer cross from one token to the other.

Llama-3.2-1B completes "If today is Thursday, tomorrow is" with " Friday". Somewhere inside it, the identity of today has to move from the day word to the last token, where the next-token prediction is made. This page finds out where — by taking the residual stream from a run on a different day and writing it into the same place on this one, at each of the sixteen layers in turn.

That is an interchange intervention. If the patched model now answers the counterfactual day's successor, the thing you swapped was carrying the answer. The metric is iia: the fraction of rows whose top token after the patch is the counterfactual's answer.

At a glance #

The crossover is between layer 11 and layer 12, and it is sharp. Up to layer 11, "today" is at the day token and the last token holds nothing; from layer 12 it is the other way round.

The data #

All 42 ordered pairs of weekdays. Every weekday name is a single token in this tokenizer, which is what makes the task scorable at one position.

The document #

Reading it in the order the compiler does:

  • model pins the checkpoint by revision and the dtype. The revision is part of the experiment, not a convenience.
  • roles maps each input role to a column: base is input, counterfactual is counterfactual_inputs[0]. Every step supplies rows for both.
  • sites names two places. target is block_output — the residual stream leaving a layer — at a layer the sweep fills in. head is lm_head, which takes no layer because it is not per-layer.
  • interventions.patching is the experiment. It reads v_cf from the unmodified model on the counterfactual prompt; it writes patch, a swap whose operand is that read; and models.patched is the base prompt run with that write applied. The second read, logits, is taken from the patched model.
  • metrics scores the logits read. iia is a match against the cf_answer column; logit_diff is the counterfactual answer's logit minus the base answer's.
  • steps.score is one observation pass over weekdays_full/data for both roles, saving the two metric tables.
the sweep axis is named

Two fields carry {"sweep": [-4, -1], "as": "pos"} — the read's position and the write's. Because they share the name pos, they move together: two points, not the four a cross product would give. The layer sweep is unnamed, so it is an axis of its own. 16 layers × 2 positions = 32 experiments, one document.

What it compiles to #

A sweep is lowered on the raw JSON before anything is compiled: each point becomes an ordinary document and is compiled on its own, with its own addresses, its own tokenization and its own digest. explain prints the whole tree, and it needs no weights:

Each point is two forwards over the same 42 rows: the counterfactual prompts through the unmodified model to get the value, then the base prompts with that value written in. pos={index:-4} is the day word — the prompts are If today is X , tomorrow is, so it is four tokens from the end — and pos={index:-1} is the token the prediction is read from.

what you need to reproduce this

Llama-3.2-1B is a gated checkpoint, so the first run needs huggingface-cli login. No GPU: the run above is CPU-only, fp32, 93 seconds wall clock including the model load, on a 12-core Ryzen 9 5900X. With --device-map cuda it is about 12 seconds (documents/real/README.md).

What the numbers mean #

Three things are visible, and each of them is a claim about the model.

The day token holds "today" through layer 11. Swapping block_output[0..10] at position −4 moves every one of the 42 rows to the counterfactual's answer — IIA 1.00, logit difference about +2.4 in favour of the counterfactual day. Early in the stack, the day word's own residual stream is the fact.

It crosses to the last token at layer 12. Between layer 11 and layer 12 the day token's IIA falls from 0.98 to 0.10 and the last token's rises from 0.00 to 0.88; by layer 14 it is 1.00 at the last token and 0.00 at the day token. The two curves are close to mirror images, which is what you want to see: the information has not been destroyed, it has moved. Layers 12 and 13 are the transition — 0.88, not 1.00 — so the move is not quite instantaneous.

Before layer 12, the last token holds nothing. IIA 0.00 and a logit difference of −2.4: patching it leaves the base answer exactly where it was. That is the control this sweep gets for free, and it is why sweeping the position alongside the layer is worth the second axis.

what this does not say

An interchange result localizes a place where the counterfactual value is sufficient to change the answer. It does not say the model computes the answer there, it does not say the representation is a direction rather than a whole activation, and at layer 15 — the last block output, one norm away from the logits — a perfect IIA is close to tautological. The neighbouring documents in documents/real/ are what narrow it: head patching finds which head does the moving, DAS finds how many dimensions carry it.

Recorded results for the same document #

The numbers above were produced by running the document on CPU while writing this page. documents/real/README.md records an earlier run of the same file on an A100 and through a self-hosted NDIF, and reports the surrounding experiments:

documentwhat it asksrecorded result
weekdays_behaviordoes the model do the task at all? 42/42 correct, p(answer) 0.45 mean
weekdays_layer_sweepthis page day token 1.00 to layer 10, 0.98 at 11, then 0.10, 0.10, 0.00, 0.00; last token 0.00 to layer 11, then 0.88, 0.88, 1.00, 1.00
weekdays_head_patchingone head's result at the last token, 32 heads × layers 10–12 one head of 96 stands out: L12 H28, mean logit difference −2.40 (median head) to +0.05
weekdays_dasa k-dim subspace of the day token at layer 8, fit on 30 pairs held-out IIA 0.00 / 0.83 / 1.00 / 1.00 at k = 1 / 4 / 16 / 64
weekdays_pattern_patchingswap only a head's attention pattern at the last token nothing moves: L12 H28 gives −2.396 against a −2.403 median

Read together: "today" sits at the day token through layer 11, crosses to the last token at layer 12 largely through one head, and is a roughly 16-dimensional subspace of a 2048-wide stream. And it is what that head moves, not where it looks — its pattern from another prompt changes nothing, while its values from another prompt change the answer.

The recorded run also notes that a self-hosted NDIF served bf16 whatever the document asked, so the remote numbers are close but not equal: the last-token sweep reads 0.86 there where fp32 reads 0.88. The two local engines — nnsight and plain forward hooks — agree exactly on all 672 numbers of a layer sweep.
